Belajar HTML dan CSS

Ringkasan materi yang digunakan dalam Praktikum 4.

1. Box Element

Setiap elemen HTML dapat dipahami sebagai kotak yang terdiri dari content, padding, border, dan margin. Keempat bagian tersebut membantu mengatur ukuran serta jarak elemen.

2. CSS Float dan Clear

Properti float dapat menempatkan elemen ke sisi kiri atau kanan. Properti clear digunakan agar elemen berikutnya tidak berada di samping elemen yang mengambang.

3. Elemen Semantik HTML5

Elemen seperti header, nav, main, section, article, aside, dan footer membantu menjelaskan struktur halaman.
