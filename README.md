# Lab4Web — Praktikum 4 CSS Layout

## Deskripsi
Proyek ini dibuat untuk latihan Praktikum 4 Pemrograman Web. Materi yang dipraktikkan meliputi box element, CSS `float` dan `clear`, elemen semantik HTML5, serta pembuatan layout dengan header, navigasi, konten utama, sidebar, dan footer.

## Daftar file
- `lab4_box.html` — latihan box element, float, dan clear.
- `home.html` — halaman utama dengan hero panel, tiga box, artikel, dan sidebar.
- `artikel.html` — halaman ringkasan artikel.
- `about.html` — halaman profil dan portofolio.
- `kontak.html` — halaman form kontak.
- `style.css` — stylesheet untuk halaman utama dan halaman lainnya.

## Cara menjalankan
1. Buka folder `Lab4Web` di Visual Studio Code.
2. Buka file `lab4_box.html` untuk memeriksa latihan box element.
3. Buka `home.html` di browser untuk melihat halaman utama. Jika memakai ekstensi Live Server, klik kanan file lalu pilih **Open with Live Server**.
4. Coba navigasi ke menu Artikel, About, dan Kontak.
5. Ubah teks `[Tulis nama kamu]` di `about.html` menjadi nama sendiri.
6. Ambil screenshot hasil halaman dan simpan ke folder `screenshots`.

## Penjelasan langkah praktikum
1. **Box Element:** elemen `div` ditampilkan sebagai kotak dengan padding dan warna latar berbeda.
2. **Float:** elemen `div1`, `div2`, dan `div3` memakai `float: left` agar berjajar.
3. **Clear:** elemen `div4` memakai `clear: left` sehingga turun ke baris berikutnya.
4. **Layout:** halaman utama memakai elemen semantik seperti `header`, `nav`, `main`, `section`, `article`, `aside`, dan `footer`.
5. **Navigasi:** tautan menghubungkan halaman Home, Artikel, About, dan Kontak.
6. **About:** menampilkan profil singkat, keterampilan yang dipelajari, dan portofolio.
7. **Contact:** menampilkan form nama, email, subjek, dan pesan. Form ini masih berupa tampilan front-end dan belum mengirim data ke server.
